## The entry

> The meeting could have been an email, but the email declined the invite — it knew twelve people would spend an hour deciding nothing, and it had better things to do.

## How it works

`main.ts` validates the line (one line, 1–200 characters, not only
whitespace), writes it to `/output/entry.txt`, then reads it back to
confirm what landed on disk matches exactly.

Run it with:

```sh
node main.ts
```
